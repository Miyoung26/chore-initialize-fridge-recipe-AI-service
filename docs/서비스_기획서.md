# 냉장고 한끼 서비스 기획서

## 1. 서비스 개요
- 서비스명: 냉장고 한끼
- 한 줄 소개: 냉장고 속 재료를 입력하면 AI가 지금 만들 수 있는 한 끼를 제안하는 서비스
- 목적: 남은 식재료 활용을 돕고 메뉴 결정 시간을 줄인다.
- 타겟 사용자: 혼자 또는 소규모로 식사하는 직장인, 자취생, 요리 초보자

## 2. 사용자 문제와 제공 가치
사용자는 냉장고에 재료가 있어도 조합 방법을 떠올리기 어렵고, 검색 결과에 없는 재료가 많이 등장해 포기하기 쉽다. 서비스는 보유 재료와 시간, 난이도, 도구, 제외 재료를 함께 반영해 실행 가능한 레시피 초안을 제공한다.

## 3. 페이지 및 섹션 구성
1. 홈: 서비스 가치와 주요 장점 소개
2. 사용 방법: 입력부터 결과 확인까지 3단계 설명
3. AI 레시피 추천: 입력 폼, 로딩, 오류, 결과 화면
4. 활용 팁: 더 정확한 결과를 위한 입력 방법
5. FAQ: 추가 재료, 알레르기, 데이터 저장 안내

상단 고정 메뉴의 앵커 링크로 각 섹션에 이동한다.

## 4. 핵심 AI 기능
### 입력
- 보유 재료, 최대 300자, 필수
- 조리 가능 시간
- 난이도
- 사용 가능한 조리 도구
- 제외 재료 또는 알레르기 유발 식품
- 인분

### 출력
- 추천 요리명과 한 줄 소개
- 예상 시간, 난이도, 인분
- 재료와 분량
- 단계별 조리 순서
- 대체 재료
- 남은 재료 활용 팁
- 식품 안전 주의 문구

### 사용자 가치
일반적인 검색보다 현재 조건에 가까운 레시피 초안을 빠르게 확인하고, 부족한 재료는 대체 아이디어로 보완할 수 있다.

## 5. 실패 처리 기준
- 빈 입력: “보유 재료를 한 가지 이상 입력해 주세요.”
- 너무 긴 입력: 서버에서 300자 제한 안내
- API 4xx/5xx: 사용자 친화적 오류 문구 출력
- 8초 이상 지연: 진행 중 안내 문구 변경
- 30초 초과: 요청 중단 후 재시도 안내
- 잘못된 AI 형식: 결과를 표시하지 않고 다시 시도하도록 안내

## 6. UX 및 반응형 기준
- 데스크톱은 입력과 결과를 2열로 배치한다.
- 820px 이하에서는 1열로 전환한다.
- 520px 이하에서는 버튼과 필드를 세로 배치한다.
- 키보드 포커스, `aria-live`, 건너뛰기 링크를 제공한다.
- 선택 보너스로 다크 모드를 제공하고 사용자 설정을 브라우저에 저장한다.

## 7. 보안과 운영
- API 키는 Vercel 환경 변수 `OPENAI_API_KEY`로만 관리한다.
- 입력 길이와 요청 크기를 제한한다.
- 서버 오류의 상세 정보는 사용자에게 노출하지 않는다.
- AI 결과는 저장하지 않으며, 서비스 화면에 이를 명시한다.
- 과금과 쿼터를 고려해 버튼 연속 호출을 방지하고 서버 타임아웃을 설정한다.

## 8. 성공 기준
- 외부 사용자가 배포 URL에서 메뉴 이동과 레시피 생성을 재현할 수 있다.
- 정상, 빈값, 알레르기 제외, 장문, 모바일 테스트를 통과한다.
- 필수 제출물 5종인 Vercel URL, GitHub, README, 기획서, 증빙을 준비한다.
